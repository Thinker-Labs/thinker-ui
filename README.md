# Thinker UI

Interactive React components with tactile materials, motion and copyable source.

```bash
npm install
npm run dev      # http://localhost:3000 redirects to /thinker-ui
npm run build
npm run props    # regenerate src/app/thinker-ui/components/props-reference.json
```

Routes: `/thinker-ui` and `/thinker-ui/components`. Needs `typescript` (dev dependency) for the props generator.
